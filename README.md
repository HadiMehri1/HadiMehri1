# Hadi Mehri — Portfolio

A responsive Persian (RTL) developer portfolio for GitHub Pages.

## Publish with GitHub Pages
1. Create a repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload all files and folders in this ZIP to the repository root. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
5. Wait a few minutes. Your site should appear at `https://YOUR-USERNAME.github.io`.

## Add skills
Edit the `skills` array near the top of `script.js`.

## Add projects
In `script.js`, add an object inside the `projects` array, for example:
`{ title: "My Project", description: "A short description", tech: ["React", "CSS"], url: "https://github.com/YOUR-USERNAME/REPOSITORY" }`

Replace the GitHub profile link and contact details in `index.html` with your own before publishing.
